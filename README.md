# AC02 · Elitium Ionic

App mobile desenvolvido para a avaliação contínua **AC02 da FIAP School**, que leva três módulos do Elitium ERP para o celular.

## Funcionalidades
- **Estoque:** produto → grupo → item, com alertas Crítico/Atenção/OK
- **Clientes:** CRUD, busca e máscaras de CPF/CNPJ e telefone
- **Leads:** filtros e "Converter em cliente"
- Consulta à **BrasilAPI** pelo CNPJ para preencher o cadastro automaticamente

## Stack
Ionic + Angular · Capacitor · Firebase (Cloud Firestore, AngularFire) · TypeScript · BrasilAPI · Vitest · ESLint

## Meu papel
Projeto em grupo em que fiz quase tudo: modelagem das coleções no Firestore, services (CRUD e exclusão em cascata com `writeBatch`), navegação em abas com rotas de detalhe, integração com a BrasilAPI e a portabilidade da lógica de alertas e formatadores do Elitium.
